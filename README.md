# adoranten
[![DOI](https://zenodo.org/badge/761981748.svg)](https://doi.org/10.5281/zenodo.18548398)

This is a repository for materials for the open access rock art journal Adoranten.  It includes files authors may need, such as the citation style files (Harvard style adapted from [Cite Them Right 12th edition - Harvard](https://www.zotero.org/styles?q=id%3Aharvard-cite-them-right) and [Current Swedish Archaeology](https://publicera.kb.se/csa/instructions)).
